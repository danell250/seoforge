# How to Use the Site Monitor

The Site Monitor continuously tracks your website's SEO health and alerts you when important changes occur. It monitors pages over time, detecting issues like broken links, lost rankings, missing meta tags, and other SEO problems that can hurt your search performance.

## What the Site Monitor Does

The monitor tracks:
- Page availability (404 errors, server errors)
- Meta tag changes (title, description)
- Content changes (word count, structure)
- Schema markup presence
- Loading speed indicators
- SEO score changes
- Link integrity

## How to Use the Site Monitor

### Step 1: Access the Tool

1. Go to [seoaxe.site](https://www.seoaxe.site)
2. Click "Login" and sign in to your account
3. Navigate to `/app` and select the **"Monitor"** tab

### Step 2: Add a Site to Monitor

1. Enter your website URL
   - Example: `https://www.yoursite.com`
2. Set monitoring preferences:
   - **Check Frequency** - How often to check (daily, weekly)
   - **Alert Threshold** - When to send alerts (any change, critical only)
   - **Pages to Monitor** - All pages or specific URLs
3. Click **"Add Site"**

### Step 3: View Monitor Dashboard

**Site Status**

### Step 5: Configure Alerts

Set up custom alerts:

**Alert Types**
- **404 Errors** - Page becomes unavailable
- **Meta Tag Changes** - Title or description modified
- **Content Changes** - Significant content modifications
- **Schema Loss** - Schema markup removed
- **Speed Degradation** - Page load time increases
- **Link Breaks** - Internal or external links break

**Alert Channels**
- Email notifications
- In-app alerts
- (Future) Webhook integrations

**Alert Frequency**
- Immediate for critical issues
- Daily digest for warnings
- Weekly summary for informational

### Step 6: Respond to Alerts

When you receive an alert:

**Critical Alerts (Immediate Action)**
- 404 errors - Fix broken links or restore page
- Schema loss - Re-add schema markup
- Major content changes - Verify if intentional

**Warning Alerts (Review Soon)**
- Meta tag changes - Check if optimized
- Speed degradation - Optimize images or code
- Link breaks - Update or remove broken links

**Informational (Monitor)**
- Minor content updates - Note for reference
- Score changes - Track trend over time

### Step 7: Monitor Trends

Use the monitoring data to:

**Detect Issues Early**

## Common Issues Detected

### 404 Errors
- **Cause**: Page deleted or URL changed
- **Impact**: Lost traffic, bad user experience
- **Fix**: Restore page or implement 301 redirect

### Missing Meta Tags
- **Cause**: Accidental removal or CMS error
- **Impact**: Lower CTR, poor rankings
- **Fix**: Re-add optimized meta tags

### Schema Loss
- **Cause**: Template update or code change
- **Impact**: Lost rich snippets
- **Fix**: Re-add schema markup

### Content Changes
- **Cause**: Content update or CMS glitch
- **Impact**: May affect rankings
- **Fix**: Verify change was intentional

### Speed Degradation
- **Cause**: Large images, slow server, code bloat
- **Impact**: Poor user experience, lower rankings
- **Fix**: Optimize images, minify code, upgrade hosting

### Broken Links
- **Cause**: Linked page removed or URL changed
- **Impact**: Poor user experience, lost link equity
- **Fix**: Update or remove broken links

## Troubleshooting

**Issue: Too many alerts**
- Solution: Adjust alert thresholds, focus on critical issues only

**Issue: False positives**
- Solution: Review alert criteria, adjust sensitivity

**Issue: Monitoring not working**
- Solution: Check site accessibility, verify monitoring configuration

**Issue: Missing important changes**
- Solution: Increase monitoring frequency, expand page coverage
