# How to Use the Single Page Optimizer

The Single Page Optimizer automatically repairs and optimizes individual web pages for SEO. It analyzes your page's HTML, identifies issues, and generates optimized HTML with proper meta tags, schema markup, and AEO answer blocks.

## What the Single Page Optimizer Does

The optimizer fixes common SEO issues:
- Missing or poorly optimized title tags
- Incomplete meta descriptions
- Missing schema markup (Article, FAQ, Breadcrumb)
- Poor heading structure
- Missing Open Graph and Twitter Card tags
- No AEO (Answer Engine Optimization) content for AI overviews
- Slow page load indicators
- Missing canonical URLs

## How to Use the Single Page Optimizer

### Step 1: Access the Tool

1. Go to [seoaxe.site](https://www.seoaxe.site)
2. Click "Login" and sign in to your account
3. Navigate to `/app` and select the **"Repair Page"** tab

### Step 2: Paste Your HTML

You have two options:

**Option A: Paste HTML directly**
1. Copy the HTML from your webpage (View Source)
2. Paste it into the textarea
3. Click **"Optimize"**

**Option B: Provide a URL**
1. Enter the URL of the page
2. The tool will fetch and analyze the HTML
3. Click **"Optimize"**

### Step 3: Configure Options (Optional)

You can customize the optimization:
- **Target Keyword** - Specify your main keyword for better targeting
- **Content Focus** - Choose blog, product, or landing page
- **Tone** - Select the writing style (authoritative, friendly, professional)
- **Include AEO Blocks** - Add FAQ schema for AI overviews

### Step 4: Review the Optimized HTML

The tool displays:
- **Original Issues Found** - List of problems detected
- **Optimized HTML** - The repaired and improved HTML
- **Changes Made** - Summary of what was fixed

### Step 5: Copy or Deploy

You have several options:

**Copy HTML**
1. Click "Copy HTML" to copy the optimized code
2. Paste it into your CMS or HTML editor
3. Replace your existing page

**Download HTML**
1. Click "Download" to save as an HTML file
2. Upload to your server or CMS

**Deploy to WordPress/Shopify** (if configured)
1. Select your platform
2. Enter your API credentials
3. Click "Deploy"
4. The tool uploads the optimized page directly

### Step 6: Verify Changes

After deploying:
1. Check that the page loads correctly
2. Verify meta tags in page source
3. Test schema markup using Google's Rich Results Test
4. Check page speed with PageSpeed Insights

## What Gets Optimized

### Meta Tags
- **Title Tag** - Optimized to 50-60 characters with keyword
- **Meta Description** - Compelling 150-160 character description
- **Canonical URL** - Prevents duplicate content issues
- **Robots Meta** - Proper indexing directives

### Schema Markup
- **Article Schema** - For blog posts and news
- **FAQ Schema** - Question-answer pairs for rich snippets
- **Breadcrumb Schema** - Navigation structure
- **Organization Schema** - Business information
- **WebPage Schema** - Page-level metadata

### Social Tags
- **Open Graph** - For Facebook/LinkedIn sharing
- **Twitter Cards** - For Twitter preview cards
- Proper image dimensions and descriptions

### Content Structure
- **H1** - Single, keyword-focused main heading
- **H2/H3** - Logical heading hierarchy
- **Internal Links** - Strategic internal linking
- **Alt Text** - Image descriptions for accessibility

### AEO Content
- **FAQ Section** - Questions and answers for AI overviews
- **Structured Data** - Machine-readable content
- **Clear Answers** - Direct responses to common queries

## Best Practices

### Before Optimizing
- **Backup your page** - Keep original HTML safe
- **Check current rankings** - Note your position before changes
- **Identify target keyword** - Know what you're optimizing for

### During Optimization
- **Review the changes** - Don't blindly accept all edits
- **Customize for your brand** - Ensure tone matches your voice
- **Test different options** - Try with/without AEO blocks

### After Optimizing
- **Monitor rankings** - Track position changes over 2-4 weeks
- **Check analytics** - Monitor traffic and engagement
- **Test on mobile** - Ensure mobile rendering is correct
- **Validate schema** - Use Google's Structured Data Testing Tool

## Troubleshooting

**Issue: Optimized HTML breaks layout**
- Solution: Review CSS conflicts, test on staging first

**Issue: Schema validation errors**
- Solution: Check required fields, use Google's testing tool

**Issue: Rankings drop after optimization**
- Solution: Revert changes, identify what caused the drop

**Issue: Page loads slower**
- Solution: Check image sizes, minify CSS/JS

## Tips for Best Results

## Common Questions

**Q: Can I undo changes?**
A: Keep your original HTML backed up. The tool doesn't store your data.

**Q: Will this affect my design?**
A: The optimizer focuses on HTML structure and meta tags, not CSS. Design should remain unchanged.

**Q: How often should I optimize?**
A: Optimize when you publish new content or when rankings drop.

**Q: Does this work with all CMS platforms?**
A: Yes, you can copy the HTML to any platform that allows HTML editing.
